## Personal knowledge base (ms-kb)

The user keeps a personal knowledge base: an Obsidian vault managed by the `kb` CLI (`kb where` prints its path).

- When the user wants to continue earlier learning, or asks what they have already studied, concluded or left unclear, use the `kb-recall` skill. Do not consult the knowledge base for questions that need no personal context.
- Save to the knowledge base only when the user asks, with the `add-knowledge` skill.
- Change the vault only through `kb`; never edit, move or delete vault files with other tools, and never run `git` in the vault.
